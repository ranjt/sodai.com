# InquiryMind science question bank (KG–Grade 5)

Original digital practice questions for the InquiryMind **Practice** section: learners practise on their own, teachers
assign sets. Every topic matches one InquiryMind science worksheet pack (`worksheets/`), and the simulation questions use
the PhET simulations in `science-simulations/`. Every question has feedback that explains the answer.

Try them: open `preview/index.html` in a browser. It has filters, a playable version of every question type, a score, and a
teacher view that shows all answers.

Live counts per grade, topic, mode and type are in `dist/manifest.json`.

## Folders

```

│   kg/, grade-1/ … grade-5/

│   └── index.json                         every picture: diagrams {name: {src, alt, key}}, openmoji {name: path}
├── dist/                                  GENERATED by tools/build_bank.py (import these into the website)
│   ├── manifest.json                      grades → topics (site skill code, counts per mode and type), totals
│   ├── all-questions.json                 every question, flat, with its grade/topic/strand fields added
│   ├── kg.json, grade-1.json … grade-5.json
│   └── questions.js                       window.QB = {manifest, questions} for the preview page
├── preview/
│   ├── index.html                         browse and play every question
│   ├── qb-player.js, qb-player.css        reusable player: renders and marks any question (no libraries)
│   └── assets/                            logo and fonts
└── tools/
    ├── validate.py                        checks every file (schema, answers, pictures, simulation ids, mix)
    ├── build_bank.py                      validate → dist/ → copy to offline-simulations/inquirymind-site/question-bank/
    └── images.py                          rebuilds images/ from the worksheet art and OpenMoji
```

## How it maps to the Practice page

| Website | Question bank |
|---|---|
| Science tab, grade buttons KG, 1–5 | `grade` (0 = KG) and `grade_name` |
| Strand: Working scientifically, Living things, Earth and space, Physical science | `strand`: `skills`, `living`, `earth`, `physical` |
| Skill code (W1, L1, L2, E1, P1 …) | `site_skill` (numbered in topic order inside each grade and strand) |
| Skill name | `title` (the worksheet pack title); `topic` is the pack code (A1, B2, C3, W1) |
| Mixed review card | `mode: "core"` |
| Picture quiz card | `mode: "picture"` (the learner must look at a diagram or picture options) |
| Real-life choices card | `mode: "real-life"` (a situation: choose the best decision, prediction or safe action) |
| Simulation questions card | `mode: "simulation"` (open the simulation, do the task, then answer) |
| Olympiad challenge card | `mode: "olympiad"` (harder reasoning, data, fair tests; difficulty 3) |
| Mixed review can also draw from every mode | filter by `grade` + `topic` only |
| Mastery | mark each answer with `QBPlayer.score()` (rules below); `subskill` gives finer reporting |

## Question format

A topic file:

```json
{"grade": 3, "grade_name": "Grade 3", "topic": "C2", "title": "Sound", "strand": "physical",
 "worksheet": "worksheets/grade-3-science/pdf/c2-sound-study-pack.pdf", "questions": [ ... ]}
```

Every question has `id` (stable, e.g. `g3-c2-013`; never reuse or renumber), `mode`, `type`, `difficulty` (1 easy,
2 medium, 3 hard), `bloom` (remember, understand, apply, analyse, evaluate, create), `subskill`, `stem`, `explanation`
(feedback shown after answering). Optional: `image` + `image_alt`, `hint`, `read_aloud` (true for KG and Grade 1: read the
question aloud), `sim` (`{id, task}` for simulation questions). `**word**` in a stem means bold.

| `type` | Fields | Learner does | Marked right when |
|---|---|---|---|
| `mcq` | `options`, `answer` (index from 0) | taps one option | the chosen index = `answer` |
| `multi` | `options`, `answer` (list of indexes) | taps every right option | the chosen set = `answer` exactly (partial score: right picks minus wrong picks, divided by the number of right answers, not below 0) |
| `truefalse` | `answer` (true/false) | taps True or False | equal |
| `fill` | stem with `___` per gap, `blanks` (list of accepted-answer lists), optional `bank` (word bank with distractors) | types or taps words | every gap matches one accepted answer (ignore case, spaces, punctuation and a leading a/an/the) |
| `match` | `pairs` ([left, right]); show the right side shuffled | joins each left to a right | every pair joined correctly (score = share right) |
| `sort` | `categories`, `items` ([item, category]) | puts each item in a group | every item in its group (score = share right) |
| `order` | `sequence` (right order); show shuffled | puts steps in order | the exact order (score = share in the right place) |
| `short` | `model_answer`, `keywords` (list of synonym lists), `min_keywords` | writes a sentence | at least `min_keywords` groups found (a word matches a keyword or keyword + s/es/ed/ing…); always show the model answer, and let teachers review |

Options, pairs, items and steps are text or `{"text": "...", "image": "openmoji/frog.svg"}`. Picture paths are relative to
`images/`. Simulation links: `science-simulations/sims/<sim.id>.html`.

## Change or add questions

1. Edit or add a file in `questions/<grade>/` (copy the style of an existing file; new ids continue the numbering).
2. `python3 question-bank/tools/validate.py` (0 errors needed; read the warnings).
3. `python3 question-bank/tools/build_bank.py` (writes `dist/` and the InquiryMind copy).

## How the questions were written

Written as an assessment designer would: from each worksheet pack's learning outcomes, study text and answer key, plus the
PhET simulations. Per topic: KG 20, Grade 1 24, Grade 2 26, Grade 3 28, Grades 4–5 30 questions; every type and practice
mode; about 40% easy, 40% medium, 20% hard; distractors taken from real misconceptions (for example "plants get their food
from the soil"); Bangladesh contexts (rivers, haor, Sundarbans, monsoon, markets, tubewells) and the wider world. Data in
olympiad and investigation questions is labelled as example data unless it comes with its source (Grade 5 C10 energy
resources).
